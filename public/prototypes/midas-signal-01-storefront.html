    How this store works: read this part

    Nothing here takes money yet. Payments are not connected. The checkout is a working mock so Midas can feel the flow: pick, name a price, get the file.

    Name your price means exactly that. The chip amounts are examples. Whether there is a minimum is Midas's call and has not been decided, so this page does not set one. License terms are also still to be set with Midas, which is why every beat says so instead of listing made-up tiers.

    The map is the real idea. Every download, even at $0, adds an opted-in email to Midas's own list. That list belongs to him, not to YouTube or a beat marketplace, and each person on it becomes a pin. The pins on the map today are samples.

    There are no photos on this page on purpose. A shoot is needed and not booked yet, so this layout is finished with type and color alone.
